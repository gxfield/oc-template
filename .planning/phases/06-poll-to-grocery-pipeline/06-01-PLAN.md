5. Read `household/meals/this-week.md`, update the matching day line with the winner, write file back

7. If NO matching recipe found: stop here (just the meal plan update is sufficient)
8. If recipe found: follow the "Recipe to Grocery List" workflow — extract ingredient names from the recipe's `## Ingredients` section, strip quantities/units per the existing rules in that section
9. List Todoist sections: `node -e "const {runTask} = require('./tasks/index.js'); runTask({task: 'todoist', intent: 'sections', parameters: {project: 'shopping'}}).then(r => console.log(JSON.stringify(r, null, 2)));"`
10. For each ingredient, match to the best section (Produce, Dairy, Meat, etc.) and add via: `node -e "const {runTask} = require('./tasks/index.js'); runTask({task: 'todoist', intent: 'add', parameters: {project: 'shopping', content: 'ITEM', section_id: 'SECTION_ID'}}).then(r => console.log(JSON.stringify(r, null, 2)));"`
11. Confirm to user: "Updated Thursday dinner to Chicken Parmesan. Added X ingredients to the shopping list."
